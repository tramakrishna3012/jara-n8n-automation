# Backend Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| POST | /jobs | Create or ingest a job posting. |
| POST | /ai/skill-match | Score candidate fit against a job. |
| POST | /ai/resume | Generate resume content for a target role. |
| POST | /automation/apply | Trigger assisted application flow. |
| POST | /automation/referral | Request or draft a referral. |
| POST | /status/update | Update application status and notes. |
| POST | /automation/error-log | Capture workflow errors for audit and alerting. |
